# Умножалка — как получить APK для Android

Игра лежит в `www/index.html`. Остальное — обёртка (Capacitor), которая превращает страницу в обычное
Android-приложение. Есть два способа получить APK.

- **Способ А (рекомендую): онлайн, на GitHub.** Ничего устанавливать не нужно, только браузер.
  Сборку делает бесплатный сервер GitHub, вы скачиваете готовый файл.
- **Способ Б: на своём компьютере через Android Studio.** Программа тяжёлая, нужно скачать несколько гигабайт.

---

## Способ А. Онлайн через GitHub (без установки программ)

Один раз настроить — минут 10. Потом каждая новая версия собирается сама за 5–10 минут.

1. **Аккаунт.** Зарегистрируйтесь на https://github.com (бесплатно).
2. **Репозиторий.** Нажмите «+» вверху справа → **New repository**. Имя любое, например `umnozhalka`.
   Можно выбрать Private (закрытый): для такой сборки бесплатного лимита хватает с запасом.
   Нажмите **Create repository**.
3. **Загрузка файлов.** На странице нового репозитория нажмите ссылку **uploading an existing file**.
   Распакуйте архив и перетащите в окно **содержимое** папки `umnozhalka` (не сам zip):
   `www`, `ci`, `.github`, `package.json`, `capacitor.config.json`, `README.md`, `.gitignore`.
   Внизу нажмите **Commit changes**.
4. **Проверьте папку `.github`.** В списке файлов репозитория она должна быть. На Mac папки с точкой
   в начале скрыты в Finder (покажет сочетание Cmd+Shift+точка). Если её нет, создайте файл вручную:
   **Add file → Create new file**, в поле имени введите `.github/workflows/build-apk.yml`
   (слэши создадут папки), вставьте туда содержимое файла `build-apk.yml` из архива
   и нажмите **Commit changes**.
5. **Сборка.** Откройте вкладку **Actions**. Если GitHub спросит про включение workflows, согласитесь
   (кнопка вроде «I understand my workflows, go ahead and enable them»). Сборка **Build APK** стартует сама.
   Рядом с ней крутится жёлтый кружок. Когда он станет зелёной галочкой, всё готово. Это занимает 5–10 минут.
   Если запуска нет, откройте Actions → Build APK → **Run workflow**.
6. **Скачать APK.** Нажмите на завершённую сборку, прокрутите страницу вниз до раздела **Artifacts**
   и скачайте `umnozhalka-apk`. Это zip, внутри файл `app-debug.apk`.
7. **Установить на телефон.** Перекиньте `app-debug.apk` на телефон (Telegram самому себе, почта,
   Google Диск, USB). Откройте файл на телефоне. Android попросит разрешить установку из этого источника
   («Установка неизвестных приложений»), разрешите. Установите.

Красная галочка вместо зелёной значит, что сборка упала. Откройте её, найдите шаг с красным крестиком,
скопируйте последние строки лога и покажите их мне, я исправлю.

### Как обновить игру

Измените `www/index.html` (на GitHub: открыть файл → значок карандаша → **Commit changes**,
или загрузить новый файл через **Add file → Upload files**). Сборка запустится сама.
Новый APK ставится **поверх** старого, рекорды при этом сохраняются: ключ подписи у всех сборок один
(лежит в `ci/debug.keystore`).

Готовые APK хранятся на GitHub 90 дней, потом их можно собрать заново кнопкой Run workflow.

## Способ Б. На своём компьютере (Android Studio)

Нужно установить:
1. **Node.js** (LTS) — https://nodejs.org
2. **Android Studio** — https://developer.android.com/studio (при первом запуске она скачает Android SDK).

Откройте терминал в папке `umnozhalka` и выполните:

```
npm install
npx cap add android
```

Затем откройте файл `android/app/src/main/AndroidManifest.xml` и внесите две правки:
- в тег `<activity` добавьте `android:screenOrientation="portrait"` (только вертикально);
- рядом со строкой `<uses-permission android:name="android.permission.INTERNET" />` добавьте
  `<uses-permission android:name="android.permission.VIBRATE" />` (вибрация при ошибке; можно пропустить).

Дальше:

```
npx cap sync android
npx cap open android
```

В Android Studio дождитесь конца загрузки внизу (в первый раз 5–10 минут), затем
**Build → Build Bundle(s) / APK(s) → Build APK(s)**. После сборки нажмите **locate** в уведомлении.
Файл лежит в `android/app/build/outputs/apk/debug/app-debug.apk`. Установка на телефон — как в п. 7 выше.

Чтобы обновить игру: измените `www/index.html`, выполните `npx cap sync android` и соберите APK заново.
Если Android откажется ставить новую версию поверх старой (сборка на другом компьютере), сначала удалите
старое приложение. При удалении рекорды стираются.

## Заметки

- Рекорды и игроки хранятся на телефоне, внутри приложения. Между телефонами не переносятся.
- Такой APK подходит для личного пользования. Для публикации в Google Play нужна подписанная
  релизная сборка и аккаунт разработчика.
- Быстро посмотреть игру без сборки: откройте `www/index.html` в браузере на компьютере.
  Играть можно и с обычной клавиатуры (цифры, Backspace, Enter).
- Название приложения меняется в `capacitor.config.json` (`appName`).
